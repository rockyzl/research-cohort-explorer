# Third-party data, models and attribution

This repository contains **code, catalog metadata and aggregate results only**. The SQLite database, raw files and per-patient tables are not redistributed (see `.gitignore`); `data/manifest.json` records the sources and SHA-256 hashes.

| Component | Source | License / terms |
|---|---|---|
| Pathology report text | TCGA-Reports, Kefeli & Tatonetti, *Patterns* 5(3):100933 (2024); Mendeley Data DOI 10.17632/hyg5xkznpx.1 | Data CC BY 4.0; code MIT |
| Clinical endpoints | TCGA Pan-Cancer Clinical Data Resource (Liu et al., *Cell* 2018) | GDC open-access publication data |
| Clinical matrix (receptors, PAM50) and RNA-seq (HiSeqV2) | UCSC Xena, TCGA BRCA sampleMap | Xena metadata: public, redistribution allowed; TCGA publication guidelines apply |
| Slide file metadata | NCI Genomic Data Commons (GDC) API, open-access metadata only | GDC open-access terms |
| LLM for text-to-SQL | Azure OpenAI GPT-4.1, called with the author's own credentials at run time | No model weights or keys are included |

The results shown here are based upon data generated by the TCGA Research Network: https://www.cancer.gov/tcga. Research and education only; not a clinical or hospital system.
